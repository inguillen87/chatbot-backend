### 3. Tracking Links (Production Ready)
*   **Issue:** Order tracking links were pointing to `localhost:8080`.

*   **Format:** `https://chatboc.ar/pyme/pedidos/<TICKET_ID>` (Public access allowed).

## 🚀 New "Smart Agent" Features (Pro Update)

### 4. Visual Search & Multimodal Inputs
The bot now processes images and files intelligently.
*   **Handwritten Notes:** Users can upload a photo of a handwritten list. The bot will extract items (e.g., "Leí: 2 vinos, 1 caja").
*   **Visual Search:** Uploading a product photo triggers a visual search in the catalog.
*   **UI Requirement:** Show a "Processing..." state when an image is uploaded, as analysis takes 2-4 seconds.

### 5. Proactive Suggestions (Smart Sales)
*   **Behavior Update:** Suggestions are now **Rate Limited**. They will NOT appear on every message (only once every ~4 turns) and are **suppressed** when the user is providing data (address/payment) to avoid distractions.
*   **Frontend Action:**
    *   **Parser Logic:** Detect suggestions by checking if the last line of `message_body` starts with **`Sugerencia:`** OR **`💡`**.
    *   **Render:** Display these as a distinct, dismissible **"Smart Hint" bubble** above the chat input.
    *   **QA Note:** If a suggestion doesn't appear immediately, keep chatting. This is intentional intelligence, not a bug.

### 6. "Mirror Catalog" (External Marketplaces)
*   **Feature:** Items can now link directly to MercadoLibre or TiendaNube instead of the internal cart.
*   **Data Field:** `item.checkout_type` (`'mercadolibre'`, `'tiendanube'`, `'chatboc'`).
*   **UI Logic:**
    ```javascript
    if (item.checkout_type === 'mercadolibre') {
      // Render "Buy on ML" button
      return <Button onClick={() => window.open(item.external_url)}>Comprar en ML</Button>;
    } else {
      // Render standard "Add to Cart"
      return <Button onClick={addToCart}>Agregar</Button>;
    }
    ```
