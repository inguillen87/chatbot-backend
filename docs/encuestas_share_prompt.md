# Prompt sugerido para generar banner de encuestas

Si necesitás crear un banner nuevo para las encuestas públicas, podés usar este prompt base en herramientas como Sora, DALL·E o Midjourney. Ajustalo con los colores e identidad de tu municipio antes de generar la imagen.

```
Diseñá un banner horizontal en formato 1200x630 px que represente participación ciudadana inclusiva. Mostrar personas diversas colaborando en un espacio público moderno, colores vibrantes y optimistas, estilo ilustración vectorial limpia. Incluir el texto grande "Encuestas Ciudadanas" y un subtítulo más pequeño "Sumá tu voz". Fondo con íconos sutiles de chat, encuestas y comunidad. Iluminación cálida, apto para usar como imagen de vista previa en redes sociales y WhatsApp.
```

Recordá exportar el resultado en formato PNG liviano y subirlo al CDN o repositorio de frontend para que el backend pueda referenciarlo mediante la configuración `encuestas.menu_image_url` o `PUBLIC_ENCUESTAS_DEFAULT_SHARE_IMAGE_URL`.
